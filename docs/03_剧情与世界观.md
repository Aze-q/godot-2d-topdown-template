**确认范围、来源与验证状态**

原始设计提供好奇心驱动、规则一致、魔法影响环境、知识成长、人物与环境共同叙事、完整结局等方向。湖底蓝光、动物绕行、老人避谈、墓碑符号与能力回访来自[原稿的湖泊例子](/Users/ze/Downloads/2D_Mystery_OpenWorld_ARPG_Design_v1.md:123)，原稿未确定其真相。

返乡伙伴、山谷水路旧灾难、人物责任及其后续事件，是基于上述方向创作并经讨论、自检和用户批准采用的第一版内容，不追溯声称它们原本就在原稿里。此前“老人为掩盖家族责任而淹碑”的旧例案已经被当前因果替换。

本文明确写出的事件、人物责任、两种当前处置与支线方向按第一版执行。场景几何、全部对白、准确年表和逐项制作状态另在文末列出，不能把这些真正未完成的细节与已经确定的设计方向混为一谈。工作名和人物中英文工作名用于保持一致，正式发行命名仍可统一调整。

文本自检只能检查因果和约束。已有竞品评论支持关注信息可读性、重复通行和多人参与等风险，不能证明本作故事有吸引力；证据与后续验证方法统一由玩法文件维护。

**世界背景与共同冒险者**

故事发生在前工业幻想山谷。渡口、聚落、工坊与旧水路长期共同维持当地生活，魔法参与日常设施与个人行动。具体王国、纪年、完整社会制度和魔法起源尚未展开，不为填满背景增加无关势力。

大型网络承担持续供给、调度与放大作用；个人法术作用于局部、短时的对象。停止大型设施，不会抹去角色学会的法术；个人施法也不能无限替代整个山谷的持续供给。主线危险由水路故障、调度与人的决定解释，不用“压力异常”笼统解释所有魔法现象。此前的“晴天结霜”不属于第一版正式情节。

玩家是旧渡驿站的学徒或旧成员，曾在这里生活、学习，后来外出。老师发现异常，请大家回乡协助。单机是一人返乡，合作是伙伴陆续归来；寻找老师、保护熟悉居民、恢复故乡生活是共同动机。经历不专属于房主，也不依赖仅一名玩家拥有的血统、记忆或命定资格。具体房间规则和输入决定权只在玩法文件维护。

六名主要人物使用以下工作名：

| 人物 | 要保住什么 | 知道、隐瞒与实际行动 |
|---|---|---|
| 艾妲 Ada，老师 | 学徒、居民和故乡生活 | 已发现地图与运行问题，提交报告、通知居民、留下路线并尝试传信；不掌握全部旧案。试运行后足部受伤，暂住旧镇安全住所有人照料；会合后继续核实证据与准备措施 |
| 欧伦 Oren，守闸老人 | 下游亲人与邻居 | 公开当前危险和封闸事实并主动求助；回避的是当年的错误登记及灾后隐瞒，不扣住能帮助当前救援的信息 |
| 马雷克 Marek，调度主管 | 供给、工坊生计与秩序 | 知道当前风险，已批准低负荷运行，也接受具体排班纠错；仍反对长期停工和承担完整安置成本，推动重开危险支路 |
| 米拉 Mira，船主 | 居民往来、渡运与收入 | 起初只收到货运安排，不知道同一渡班还被写入撤离通知；核对矛盾后暂停出港、调整当次安排，并承担货物推迟造成的收入代价 |
| 塔文 Tavin，工匠 | 工人生活与手艺的延续 | 能解释基本供给、大工坊停产和设备隔离的区别；协助验证可行办法，也明确表达停工和转业的损失 |
| 蕾娜 Lena，现居区代表 | 居民安全与可持续生活 | 提供实际居住和撤离情况，参与公开讨论；要求措施落实到人，不能以纸面通知代替真实安置 |

艾妲足伤后无法独自通过高道的陡梯和狭路，玩家仍能沿该路提前到达她的位置。她并非握着一根必须永远操作的拉杆等待救援，也没有放弃传信。蓝湖退水、连续步行路线畅通后，以短同行段落返回驿站；不增加强制护送战斗或独立跳跃系统。

**贯穿问题与历史因果**

> 为什么每次保护山谷，都让同一个地方承担危险？

第一版逐步回答：危险既来自设备和流向，也来自把下游视为可以转嫁损失的区域、把书面完成当作事实完成的决策方式。玩家要分清事故、失职、知情决定与隐瞒，不能把所有责任推给最早遇见的可疑老人。

| 时间关系 | 世界中实际发生的事情 |
|---|---|
| 数十年前，洪灾撤离期间 | 欧伦在主码头未见候船者，未经逐户核查便签下“全区清空”。后街居民并未全部撤离 |
| 当年开闸之前 | 欧伦发现遗漏，送出更正；上级已经收到未撤完的消息，仍为保护上游主动提前泄洪 |
| 灾难之后 | 居民记得洪灾与死者。被隐瞒的是提前开闸的经过、知情情况及责任；欧伦隐瞒了自己的失职。没有“删去地图就使所有人失忆”的设定 |
| 后来的再居住 | 受影响地带重新出现居民，现行调度图仍沿用过时的废弃区分类。旧镇遗迹与现居区并非同一片不可区分的场景 |
| 最近试运行之前 | 艾妲调查实际居住与图纸差异，向调度处报告并请旧伙伴回乡协助；她继续到旧镇一侧核查 |
| 最近的高负荷试运行 | 设备故障暴露危险流向，异常水量进入旧支路。欧伦封住蓝湖通向现居区的危险出口；试运行随后停止，入湖闸关闭 |
| 玩家调查期间 | 蓝湖滞留有限积水；上游正常河道保持通行，整个网络维持较低负荷。基本生活可以继续，但大型工坊停产、部分供给和收入下降 |
| 当前冲突 | 马雷克主张恢复高负荷，沿用危险方案；实际居住、客货安排和撤离确认尚未支持他的计划 |
| 公开事实与处置 | 玩家和受影响群体核实证据、比较办法、落实当前措施；历史责任公开，世界和人物承担实际后果 |

以上相对先后是正式因果。具体日期、各文书编号和设备失效组件仍需在场景制作中对应，不假称已经完成完整年表或设施设计。当前低负荷足以维持调查期的基本稳定，没有隐藏的现实时间灭城倒计时；危险不会为了制造紧迫感而在玩家做支线时自行兑现。

**世界连接与四段主线**

渡驿是生活据点，主要冒险地区为蓝湖、林岭与旧工坊、淹没旧镇、高堤中枢。连接关系服务不同调查顺序：

- 从渡驿可以先去蓝湖，也可以先去林岭与工坊。
- 林岭高道一直允许玩家进入旧镇高街；蓝湖安全分流后开放进入低街的旧驿道。
- 工坊上堤路通向中枢外院，玩家可以提前见马雷克、查看运行情况。
- 旧镇侧可打通检修廊，为进入中枢控制区域提供另一条路。
- 实际通路、门槛和回访成本由玩法文件维护；剧情不把“读完固定页数”作为道路或设备突然可用的原因。

四段分别让玩家处理眼前异常、检验当前承诺、重走历史现场和实施公共决定。地区内还保留生态、工艺、私人往事等独立内容，避免整部冒险反复执行修闸任务。

**第一段：蓝湖——有限积水与安全分流**

玩家首先看见蓝光、动物退避、被淹的旧路与居民受到的影响。欧伦说明封闸事实和当前危险。核心问题是蓝光如何产生、水为什么退不了，以及怎样避免把积水继续送进现居区。

本次异常试放水已经结束，入湖闸已关。欧伦的封堵使高水位滞留，水淹到旧设施的进水报警结构，产生蓝光脉冲并惊走动物。最初的异常放水早于封堵；欧伦造成滞水，也阻止了危险向居民区继续传递，不能把全部事故都归因于他。

| 水路部分 | 必须满足的实际关系 |
|---|---|
| 上游正常河道 | 保持正常通行；关闭入湖闸不是堵死整条河流 |
| 入湖口 | 本次输入已经停止，调查期不存在持续大量灌入蓝湖的上游来水 |
| 危险出口 | 通向现居区，始终保持封堵；普通安全分流操作不能误开它 |
| 分流支渠入口 | 底槛对应安全水位；湖水降到该高度后自然停止向支渠继续流动 |
| 局部缓冲池 | 与现居区流路隔开，实际空余空间能容纳本次超高积水；水位标记、去向和溢流条件可现场核查 |
| 事件完成 | 缓冲池接纳本次有限积水；不能被当成持续承接整个山谷来水的无限容器 |

缓冲容量、入口高差、分水地形和通路必须在关卡几何中验证。设计用状态或简化刻度只用于检验关系，不伪装成真实水文计算，也不要求玩家做体积算术题。“无人采石坑看起来够大”不能充当安全结论。

| 场景与方向 | 玩家实际行动 | 兑现的内容 |
|---|---|---|
| 湖岸与现居区方向 | 看新旧水痕、封堵、冲刷痕和居民区位置；听欧伦公开说明危险 | 明白原出口为何不能无条件打开；获得可继续核查的问题 |
| 干岸泵房 | 无需冰即可沿干岸步道进入；火烧枯藤可缩短路程，也保留绕行。固定取得冰教学符片，在浅水处试用 | 能力立刻产生新行动，不靠随机掉落或先有冰才能拿冰 |
| 报警结构 | 对照进水痕与记录，让报警试片接触水，观察局部蓝光 | 用动作验证进水与蓝光的关系。关闭或取下局部试片不等于湖水已经安全 |
| 岛台 | 从岸边能先看见；获得冰后走浅水，也可走较长高岸路线；到达后打开永久木桥 | 得到检修信息与探索回报，回程更方便；岛台不垄断必要证据 |
| 岩甲兽领地 | 根据领地和路线选择战斗、诱导或绕行，运用已学的材质规律 | 一次可表达判断的遭遇，核心进度不绑在唯一击杀手段上 |
| 支渠与缓冲池 | 清除卡住分流闸的阻碍，实际检查空间、入口和去向；控制位置能够看见相应现场 | 实际条件满足后即可操作，不查日志是否读满 |
| 受控分流与退水 | 开放安全支渠，水降至入口底槛后自动停流；再关闭分流设施 | 湖水下降、主报警停止、动物逐渐回来；旧路、维修棚下层与碑文显露 |

开场水道路碑与退水后的纪念碑是不同物件。前者帮助核对路线，后者记录地方记忆；碑文不能直接代替完整罪责证据链。维修棚的武器与工艺奖励规则见玩法文件。

| 状态 | 分流之前 | 分流之后 |
|---|---|---|
| 入湖闸与危险出口 | 关闭／封堵 | 仍关闭／仍封堵 |
| 湖与缓冲池 | 湖面超高，池中有余量 | 湖面安全，池中承接本次积水 |
| 报警与动物 | 主报警工作，动物退避 | 主报警停止，动物渐返 |
| 旧驿道与维修棚下层 | 被水阻挡 | 可持续访问 |
| 冰获取点、岛台、必要记录 | 可按路线取得或核查 | 保留，遗漏者仍能回访 |
| 水痕、报警结构与试片 | 支持现场判断 | 仍可复查，试片可做局部验证 |
| 已打开的木桥与捷径 | 按玩家行动开放 | 不为回访恢复成同一阻碍 |

玩家可以先安全分流，再补查欧伦动机；先到旧镇高街的玩家也可以先知道当地居住历史。后来者能够核查保留事实，但局部试验和日志不等于重新经历第一次湖面异常。多人共享进度和缺席权益由玩法文件负责，不要求八人同时做同一个操作。

**第二段：林岭与工坊——一艘船，两份承诺**

小磨坊仍在运转，大工坊已经停产。码头正在装货，居民却持有同一渡班的撤离通知。这个矛盾指向安排未落实，不能一开始就推定米拉明知故犯。

| 调查方向 | 玩家行动与验证 | 得到的答案或变化 |
|---|---|---|
| 林岭高道 | 找艾妲留下的标记，观察护幼野猪及幼兽位置，选择绕行或战斗；沿陡梯和狭路进入旧镇高街 | 可以提前会合老师；第一版不增加独立跳跃系统 |
| 工坊与码头 | 登船查看实际客位，对照居民通知和货运排班，向米拉说明冲突 | 米拉核实自己此前只收到货运安排，暂停出港，修改当次客货安排；货物推迟造成真实收入损失 |
| 供给现场 | 沿可见传动关系查看小磨坊、基本供给和停用的大型设施，与塔文核对 | 低负荷不是所有生活都停摆，但停工和收入问题也是真实的 |
| 工坊教学台 | 固定取得雷的教学内容；在训练构装旁操作隔离开关，观察相应供能切断后的停机 | 得到新能力与可用于中枢的隔离知识，个人法术不依赖恢复整个网络 |

马雷克接受具体排班纠错，但仍反对长期停工和承担完整安置成本，继续主张恢复高负荷。他不能以“完全不知道下游有人”回避已经送达的报告，也不被写成拒绝任何安全行动的人。

事件后客货安排公开，林路永久捷径开放。下一问题来自玩家亲眼核实的差异：当年的“撤离完成”是否也只在纸上成立？供能旁路首先在这里得到可重复的演示，中枢不临时改变同类装置规则。

**第三段：旧镇——没有被看见的后街**

旧登记写着全区清空，纪念地却留下后街遇难者姓名。从主码头的实际位置看不到后街。玩家既调查记录，也亲身理解当时登记者忽略了什么。

| 调查方向 | 玩家实际经历 | 推进内容 |
|---|---|---|
| 高墓道与高街 | 提前见到艾妲和现住户，取得旧登记的线索；沿现有陡梯、楼梯和院落找后街通路 | 艾妲可以参与核实，不必等所有地区事件完成才出现 |
| 退水旧驿道与低街 | 根据房号、渡口标记和水痕寻找原有出路，进入第二个小渡口 | 理解后街居民并不必然经过主码头，码头无人不能推出全区清空 |
| 礼拜堂外与邻屋 | 面对占据外围的野兽，选择战斗或邻屋楼梯高路 | 两条路线汇合，行动与观察构成调查过程，不只有依次读取文献 |
| 旧公所高层 | 在保持干燥的档案空间核对登记、更正及相关材料，再与人物回应交叉验证 | 不使用普通纸张浸水几十年仍完好的便利设定；具体文书与时序要互相对应 |

今天的地形只能帮助理解视野与路线，不足以单独证明几十年前的全部状态。对欧伦和上级的责任判断仍由当年记录、更正、送达回执、后续命令及人物回应共同支持。中枢外院的材料允许提前取得，不把关键证明临时藏到只能在结尾进入的房间。

欧伦最终说明：他在主码头未见人便未经核查签了全区清空；发现遗漏后送出更正，上级收到后仍提前开闸；他在灾后隐瞒自己的失职。他后来保护居民的行动不自动抵消这两项责任，也不能替上级承担所有知情决定的责任。

事件开放高低街通路、纪念地与通往中枢的检修廊。蓝湖退水后的连续步行路线畅通时，艾妲可以短同行返回驿站，继续参加核实与公共讨论。下一问题是：已经知道旧事的人，能否改变现在相似的决策方式？

**第四段：高堤中枢——停止命令之后怎么办**

玩家可以提前进入外院，看见低负荷运行、准备重开的危险支路和未落实的撤离安排。马雷克知道风险，却认为恢复生产更紧迫；玩家已能用现场和报告讨论其计划的具体问题。

| 进入方向 | 玩家行动 | 规则与结果 |
|---|---|---|
| 正面外院 | 交代调查发现，与马雷克和操作员交涉；面对封锁控制通路的构装，可战斗突破 | 交涉回应已知事实；战斗沿用已学规则，守卫不因剧情临时无敌 |

**公共授权与两种当前处置**

驿站的公开讨论由受影响居民、渡运者、工坊与上游群体参与，代表由各自群体推举。蕾娜带来实际居住与撤离条件，米拉说明渡运安排，塔文说明供给和转业条件；玩家提供可查证的事实、提出立场并承担执行。

公共讨论明确基本饮水、实际安全、不得以书面确认代替落实，以及各项损失由谁承担。玩家能够现场止险，但不因此取得单方面永久处置所有人生活的权力。联机中由谁输入确认只链接玩法规则，不能替代故事中的公共授权。

| 当前处置 | 实际实施 | 保住的生活与需要承担的代价 |
|---|---|---|
| 保留缩小的网络（低负荷保留） | 隔离危险支路，限制运行负荷，公开调度和维护记录，保留已经核实的基本供给 | 饮水、磨粮、小工坊继续运行；大工坊暂不能复产，部分工人转向修造或其他工作，货运与收入受影响，仍需持续维护和分配讨论 |

两项是当前已经准备并满足居民基本条件的处置，不宣称穷尽全部合理办法。未来更换主机构、重新勘测、恢复更多产业或扩建仍可讨论，需要新的资源与公共决定。不能为了制造二选一而宣布技术修复永远不可能，也不安排隐藏物品让所有收益同时保留、所有代价消失。
